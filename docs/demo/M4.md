# Demo note M4: Polish, performance and packages

This note shows the result of milestone M4.

## What M4 gives

- Search in all three modes (Ctrl+F). The options are: match case, whole
  words, wildcards (`*` and `?`), and the fields to search (names, types,
  port names, port values and conditions). The canvas marks the matches.
- Light and dark themes, and a theme that follows the system. The status
  colours are safe for colour-blind users.
- A help dialog with all keyboard shortcuts (F1).
- Performance work for large trees (see "Evidence").
- Packages:
  - A Debian package: `cargo deb -p fasttick-app`. The file goes to
    `target/debian/`.
  - An AppImage: `tools/build-appimage.sh`. The file goes to
    `target/appimage/`.
- `THIRD_PARTY_LICENSES.md`, made by `cargo about`.
- A user guide: [docs/USER_GUIDE.md](../USER_GUIDE.md).

## Try it

1. Run `cargo deb -p fasttick-app`.
2. Install the package: `sudo apt install ./target/debian/fasttick_0.1.0-1_amd64.deb`.
3. Start FastTick from the application menu, or run `fasttick`.
4. Open a tree file. Push F1 to see the keyboard shortcuts.
5. Select **View** > **Theme** > **Dark**.

## Evidence

All times are from a release build on the development container (no GPU;
the measurements do not include the GPU work).

| Case | Nodes | Time |
|---|---|---|
| Canvas frame, all nodes visible (plain boxes) | 5,000 | UI pass 0.6 ms, tessellation 2.7 ms |
| Canvas frame, full cards at 100 % | 5,000 | UI pass 0.2 ms, tessellation 0.3 ms |
| One keystroke in the inspector (edit, validation, new canvas tree, next frame) | 5,000 | about 14 ms |
| Automatic layout | 10,000 | about 2 ms |
| Search in a project | 10,000 | about 3 ms |

Commands:

- `cargo test --release -p fasttick-app --test canvas_perf -- --nocapture`
- `cargo test --release -p fasttick-app --test edit_perf -- --nocapture`
- `cargo test --release -p fasttick-core --test layout_perf -- --nocapture`
- `cargo test --release -p fasttick-core --test search_project -- --nocapture`

## Limits

- The XML panel is read-only (the brief makes an editable XML panel
  optional).
- FastTick does not convert BT.CPP v3 files to v4 (optional in the brief).
