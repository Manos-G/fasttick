FastTick 0.1.0 is the first release of FastTick: a fast tree editor, live
debugger and log replayer for BehaviorTree.CPP 4. All features are free
(MIT licence).

## Install

**Ubuntu, Debian and Raspberry Pi OS (64-bit).** Type this command in a
terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/Manos-G/fasttick/main/install.sh | sh
```

The script downloads the Debian package for your computer (amd64 or
arm64), checks its SHA-256 checksum and installs it with `apt-get`. Type
the same command again to update FastTick.

**Other files of this release:**

| File | For |
|---|---|
| `fasttick_0.1.0_amd64.deb`, `fasttick_0.1.0_arm64.deb` | Ubuntu 22.04 or later, Debian 12 or later (`sudo apt install ./fasttick_0.1.0_amd64.deb`) |
| `FastTick-0.1.0-x86_64.AppImage`, `FastTick-0.1.0-aarch64.AppImage` | Other Linux systems with glibc 2.35 or later (`chmod +x`, then start it) |
| `FastTick-0.1.0-windows-x86_64.zip` | Windows 10 and 11, 64-bit. Extract it and start `fasttick.exe`. |
| `FastTick-0.1.0-macos-arm64.zip` | macOS 11 or later on Apple silicon. Extract it and move `FastTick.app` to Applications. |
| `SHA256SUMS` | The SHA-256 checksums of all files (`sha256sum -c SHA256SUMS`) |

The Windows and macOS programs have no code signature. On Windows, click
**More info** > **Run anyway**. On macOS, the first time, right-click the
app and select **Open**.

## Features

- Edit BT.CPP 4 XML files without loss of data: comments, attribute order
  and white space stay. Projects with more than one file (`.ftproj`).
- A tree editor: drag and drop, the add dot with fuzzy search, copy and
  paste, undo and redo, automatic layout, an inspector for ports and
  conditions, SubTree tools, node models, validation with the rules of
  BT.CPP, an XML panel and search.
- Live debugging of an executor that runs the BT.CPP publisher: live
  status, blackboards, breakpoints, forced results and recording.
- Replay of `.btlog` files and SQLite logs: timeline, transitions,
  statistics, JSON and CSV export.
- Files on a robot over SSH: open, edit and save the tree files of a robot
  without a monitor. FastTick warns if a file changed on the robot, can
  restart the robot program after a save, and connects live mode to the
  robot (**Debug this robot**).
- Copies of unsaved changes: after a crash or a power cut, the next start
  offers to restore them.
- Command search (Ctrl+Shift+P), SVG export, twelve themes, and smooth
  work with trees of 5,000 nodes.

See the [user guide](https://github.com/Manos-G/fasttick/blob/main/docs/USER_GUIDE.md).
