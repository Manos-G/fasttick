FastTick 0.1.4 corrects Ctrl+F.

## Update or install

**Ubuntu, Debian and Raspberry Pi OS (64-bit).** Close FastTick, then
type this command in a terminal. It installs FastTick, or updates it to
this version:

```sh
curl -fsSL https://raw.githubusercontent.com/Manos-G/fasttick/main/install.sh | sh
```

On other systems, download the file for your computer below.

## Corrected

- **Ctrl+F** (**Edit** > **Find…**) now always puts the cursor in the
  **Find** field. Before, it did not do this when another part of the
  window had the keyboard focus, for example the canvas after a click on
  a node. Ctrl+F also selects the old search text, so that you can type
  a new search at once.
