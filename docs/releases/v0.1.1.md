FastTick 0.1.1 adds two editor features and fixes four problems.

## Update or install

**Ubuntu, Debian and Raspberry Pi OS (64-bit).** Type this command in a
terminal. It installs FastTick, or updates it to this version:

```sh
curl -fsSL https://raw.githubusercontent.com/Manos-G/fasttick/main/install.sh | sh
```

On other systems, download the file for your computer below (see the
[user guide](https://github.com/Manos-G/fasttick/blob/main/docs/USER_GUIDE.md),
section 1.1). Close FastTick before you update it.

## New

- **Delete a node and keep its children.** Select a node and push
  Ctrl+Delete (or **Edit** > **Delete, keep children**, or right-click the
  node). FastTick deletes the node, but each child (with its own children)
  becomes an unconnected node. One Ctrl+Z undoes it.
- **Connect an unconnected node from its dot.** An unconnected node has a
  dot on its top edge. Drag from the dot to a new parent: a node that can
  take one more child gets it as its last child. Release on an action (or
  another node without children) to put the node before or after it.

## Fixed

- After an edit on more than one node (for example Duplicate), all the
  nodes stay selected. Before, only the first node stayed selected.
- A file in a folder that is a link (on a robot, or `/var` on macOS) has
  one path only. Before, FastTick could copy it two times.
- An upload to a robot with a BSD or macOS system keeps the permissions of
  the file.
- The dialog that restores unsaved changes after a crash keeps its width
  with long paths.
