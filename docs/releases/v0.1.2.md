FastTick 0.1.2 changes how Delete works and keeps unconnected nodes at
their places.

## Update or install

**Ubuntu, Debian and Raspberry Pi OS (64-bit).** Close FastTick, then
type this command in a terminal. It installs FastTick, or updates it to
this version:

```sh
curl -fsSL https://raw.githubusercontent.com/Manos-G/fasttick/main/install.sh | sh
```

On other systems, download the file for your computer below.

## Changed

- **Delete keeps the children.** The Delete key (and **Edit** >
  **Delete**) deletes the selected node, but its children stay as
  unconnected nodes. **Ctrl+Delete** (**Delete with children**) deletes
  the node with all its children, as Delete did before.
- **Unconnected nodes stay at their places.** After a delete, the
  children stay where they were on the canvas. A node that you disconnect
  stays where you drop it. Drag an unconnected node to an empty place to
  move it. If an unconnected node covers a node of the tree, FastTick
  moves it down a little. A project file (`.ftproj`) saves the places.
- After an edit, the view moves only if the changed node is not visible.
  Before, it always moved to the node.
