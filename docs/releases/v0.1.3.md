FastTick 0.1.3 adds notes and groups. FastTick saves them in the XML
file. BT.CPP ignores them, so your trees run the same.

## Update or install

**Ubuntu, Debian and Raspberry Pi OS (64-bit).** Close FastTick, then
type this command in a terminal. It installs FastTick, or updates it to
this version:

```sh
curl -fsSL https://raw.githubusercontent.com/Manos-G/fasttick/main/install.sh | sh
```

On other systems, download the file for your computer below.

## New

- **Node notes.** Select a node and type a note in the **Note** field of
  the Inspector. A note mark shows on the card; the tooltip shows the
  text. Saved as `_note` on the node.
- **Groups.** Select nodes, right-click and select **New group** (or push
  Ctrl+G). A box goes around the nodes, with a title and a description.
  Drag a side or a corner of the box to change the nodes in the group:
  on release, the group takes the cards inside and snaps around them with
  a margin. Double-click the title or the description to change it, or
  use the Inspector. Right-click the title for the color and **Delete
  group**. The layout keeps other cards out of the boxes. Saved as
  `_group` on the nodes and `_group_<n>` on the `<BehaviorTree>` element.
- **Canvas notes.** Right-click an empty place and select **New note**.
  Drag the note to move it, drag a side to resize it, double-click to
  change the text. Saved as `_note_<n>` on the `<BehaviorTree>` element.
- The SVG export shows the groups, the canvas notes and the note marks.

See section 3.9 of the user guide.
