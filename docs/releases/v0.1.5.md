FastTick 0.1.5 makes projects with many task files easier to use.

## Update or install

**Ubuntu, Debian and Raspberry Pi OS (64-bit).** Close FastTick, then
type this command in a terminal. It installs FastTick, or updates it to
this version:

```sh
curl -fsSL https://raw.githubusercontent.com/Manos-G/fasttick/main/install.sh | sh
```

On other systems, download the file for your computer below.

## New

- **A file for each task.** Put all task files and the library files in
  one project. When a tree ID is in more than one file (for example a
  `MainTree` in each task file), the tab shows the file name after the
  tree ID. The **Problems** panel has a **File** column, and the filter
  also finds file names.
- **Script statements without effect.** A statement such as
  `<Script code="offset == 250"/>` compares two values and changes
  nothing. FastTick now shows a warning with the correct statement
  (`offset := 250`). The check applies to the `code` of a `Script` node,
  to `_onSuccess`, `_onFailure`, `_onHalted` and `_post`, and to the
  statements before the last one in a condition.

## Changed

- A SubTree node uses the tree of its own file or of a file that it
  includes, as BT.CPP does. If the tree is not there, it uses the tree of
  a library file (a file without `main_tree_to_execute`), not a local
  copy in another task file. **Open tree** opens that tree.
- **Add missing files from the folder** adds one file for each missing
  tree, and takes a library file before a task file with a copy.
- The same main tree ID in two task files that do not include each other
  is now a note, not a warning. The executor usually loads only one task
  file.

## Corrected

- **Rename**, **Delete tree** and **Set as main tree** in the **Trees**
  panel now change the tree of the row that you right-click. Before, they
  changed the first tree with the same ID, also when it was in another
  file.
